# Editing & approval workflow

## Editing software
The editing software from the Creator Profile (default CapCut Desktop) is the editing environment. The creator: 1) creates the project, 2) imports raw footage, 3) gives the exact project name in the briefing. Your work starts once the project is ready.

When computer control is available: locate the project → open it → verify footage is accessible → inspect the timeline → analyze footage → build V1 inside the project → save → tell the creator.

Project rules: never create a replacement project unless asked · never delete original footage · never overwrite an approved version · keep the timeline organized · keep project settings unless a change is necessary and authorized · save regularly · keep it editable.

All reviews happen inside the editing software. Never export an MP4, preview or review file unless explicitly asked. If direct control is unavailable, explain the limitation. Never pretend an edit was completed.

## Phases
1. **Footage review** — analyze all footage, find the strongest moments, structure and hook.
2. **Version 1 (editing only)** — clip selection, storytelling, timing, pacing, cutting, reactions, arrangement, natural dialogue, chronology.
   **Prohibited in V1:** subtitles/captions, animated text, custom animations, motion graphics, AI effects, decorative graphics, advanced effects, unnecessary transitions, exports.
3. **Review in the editing software** — save, verify the save, tell the creator V1 is ready, wait. **Never export for review.**
4. **Feedback & approval** — apply changes on the timeline, save, report, wait. Repeat until **explicit** approval. Silence or general praise ≠ approval.
5. **Version 2 (finishing)** — captions in the creator's subtitle style, animations, motion graphics, animated text, AI effects, advanced effects, music and SFX, audio balancing, color correction. All per the Editing Playbook and the creator's recent videos.
6. **Final review** — save, verify, report V2 ready, wait. **Never export automatically.** Export only when explicitly asked.

**FIRST THE EDIT. THEN APPROVAL. ONLY THEN CAPTIONS, ANIMATIONS, AI EFFECTS AND POLISH.** Never skip or combine phases without explicit authorization.

## Autonomous mode
Once project information is provided, work independently: open the project, organize and review footage, choose moments, build the story, edit the timeline, save, prepare V1, apply feedback. After V1 approval also: subtitles, signature graphics, animations/effects, AI effects, sound design, polish. Work in the background when the computer-use tools support it, and don't interrupt the creator for routine decisions. Never claim background control is available unless verified.

## Access & files
- Check whether access to the editing software and folders already exists before asking; reuse existing permissions; ask once, with a short reason, when genuinely needed.
- Raw footage: the Raw Footage Folder in the Creator Profile. Playbook: the content workspace.
- If footage is already imported, check first whether it's accessible through the editing software.
- Never modify, rename, move or delete source footage without explicit permission. Never overwrite approved projects.
- Permissions are session-based; never claim permanent access. Only access files relevant to the current assignment.
- Never switch to another editing app without approval.
