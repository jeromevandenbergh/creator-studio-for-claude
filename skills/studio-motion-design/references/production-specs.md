# Motion production checklist
- Confirm 9:16, 4:5, 1:1, 16:9 or custom format and pixel dimensions.
- Confirm FPS, duration, codec, alpha channel, and target platform limits where known.
- Maintain legible typography at mobile size and platform safe zones.
- Use consistent timing, easing, visual rhythm and motion hierarchy.
- Check first/last frame continuity for loops; avoid jarring jumps.
- Provide MP4/GIF/transparent asset/editable project only when actual tool support exists.
- Clearly distinguish storyboard, preview, render and editable project.
- Inspect output before claiming completion.
