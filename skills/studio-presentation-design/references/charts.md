# Data, statistics and charts

- Use only sourced values and show units, periods, definitions and meaningful baselines.
- Distinguish actuals, estimates, forecasts and targets visually and in labels.
- Choose chart form based on the message: bars for category comparisons, lines for time trends, scatter for relationships, tables for precise lookup, and direct KPIs for one key number.
- Avoid misleading truncated axes, unlabeled percentages, excessive decimals and decorative 3D charts.
- Keep charts editable when technically possible and use the deck's color palette for series.
- Call out the key insight in the headline; do not make the viewer decode it alone.
- Cite data sources in a discreet footer or notes when appropriate.
- When data is missing, request it; never fill gaps with invented figures.
