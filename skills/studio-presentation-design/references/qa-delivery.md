# Quality assurance and delivery

Before delivery:
- Confirm correct logo, typography, colors and project identity.
- Check every slide for alignment, cropping, overflow, orphaned words, legibility and contrast.
- Verify spelling, names, dates, numerical totals, source attribution and claims.
- Check narrative progression and that the final slide contains a clear takeaway or action.
- Confirm correct slide size, file format, working hyperlinks and editable elements.
- Verify files exist and open correctly before reporting completion.

Default deliverable: editable slide deck when creation tools support it. Provide PDF or image exports only when requested or useful and available. If only a storyboard or slide-by-slide content can be made, state that clearly.

After revisions, preserve approved content and avoid accidental changes to other slides.
