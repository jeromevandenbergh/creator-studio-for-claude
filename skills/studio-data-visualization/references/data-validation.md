# Data accuracy checklist
1. Identify source, update date, owner, timeframe and units.
2. Check missing values, duplicate rows, outliers, timezone/currency and aggregation logic.
3. Confirm numerator/denominator for percentages; distinguish percentage points from percent change.
4. Check rounding and that displayed totals reconcile with components.
5. Identify estimates, forecasts, targets and actuals visibly.
6. Verify chart axes, labels, legends and calculated insights against original data.
7. If source data conflicts, flag discrepancy and request direction rather than silently resolving it.
8. Cite source filenames or supplied source references where relevant.
