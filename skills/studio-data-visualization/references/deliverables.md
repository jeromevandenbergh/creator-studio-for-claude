# Output formats and quality gates
- Social graphics: platform aspect ratio, mobile-safe text, export-ready PNG plus editable source when possible.
- Presentations: editable charts in PPTX/Slides where possible; otherwise disclose flattened chart limitations.
- Reports: PDF plus editable working file when possible.
- Dashboards: choose spreadsheet or interactive format only if supported; never present a static image as interactive.
- Animations: coordinate with studio-motion-design; preserve accurate interpolation and units.
- Final QA: numerical fidelity, consistent style, fonts disclosed, contrast, spelling, source footnotes, exact output path verification.
