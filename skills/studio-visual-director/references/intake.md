# Creative intake

Use one concise interactive form where supported, otherwise a compact numbered message. Only ask unanswered relevant questions. Ask in the creator's chat language (Creator Profile).

1. **What are we making?** Instagram post / carousel / Story / ad / poster / thumbnail / presentation / infographic / animation / other (free text).
2. **What's the goal?** Inform / entertain / persuade / sell / promote / show results / engagement / other.
3. **For whom?** Followers / potential partners / clients / general audience / internal stakeholders / other.
4. **Which direction?** Bold & impactful / premium & minimal / energetic & dynamic / editorial / playful / cinematic / surprise me.
5. **Which format?** 4:5 / 9:16 / 1:1 / 16:9 / A4 / custom; ask about editable file or export preference if relevant.
6. **Which materials?** Ask explicitly: "Are there specific photos, texts, statistics, documents or visual references I should use?" Multi-select and allow attachments.

For complex assignments clarify number of slides/frames, required headlines, CTA, deadline and language if unknown. Avoid asking about minor art-direction choices the designer can make independently.
