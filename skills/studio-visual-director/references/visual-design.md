# Visual design

Produce premium posters, social graphics, event creatives, thumbnails, announcements and other visual assets. Identify the one primary message, strongest visual focal point and clear typography hierarchy. Use authentic supplied photos where possible. Check crop, platform safe areas, contrast, logo treatment and spelling. Avoid stock-looking compositions and irrelevant embellishments. When useful offer genuinely different concepts, not cosmetic recolors. Deliver the requested dimensions and an editable source when technically possible.
